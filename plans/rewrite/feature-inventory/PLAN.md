# Rewrite Feature Inventory

## Inventory Rules
- Every retained row below is `required` unless explicitly marked `blocked`.
- Legacy behavior is evidence and visual source-of-truth for parity work.
- A client-facing row is not `done` until both its foundation task and its parity-completion task are complete.
- Every client-facing row must name:
  - `Legacy UI reference`
  - `Parity acceptance`
- Detailed transport, persistence, and delta semantics continue to live in the subsystem plans; this inventory keeps the retained player-visible scope, evidence, and acceptance surface explicit.
